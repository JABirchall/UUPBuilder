`platform.OwnedTree` borrows the exact private local NTFS workspace and retains parent/root/created-entry handles and native volume/file IDs. It rechecks the owner marker's identity/content. It deletes exact held file objects, never recursively deleting an arbitrary path. For directories it closes the no-rename pin only after proof, opens a single leaf relative to a retained parent, rechecks the original native ID and then marks that exact object for deletion. A missing or replaced final root refuses. Cancellation/partial close/removal errors are retained; Close releases handles and explicitly reports unresolved preservation rather than claiming deletion.

An unresolved directory claim always makes generic jobstore resource inspection preserve/refuse. The generic regular-file, one-link, no-reparse checkpoint/topology guards and their limits remain strict. Release requires an empty same-identity scope and complete independent nonoverlapping OS mount inventory plus bounded generic workspace topology. This is a bounded observation, not an atomic metadata snapshot or image-preservation proof.
